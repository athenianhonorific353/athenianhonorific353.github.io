## 🔧 Installation Guide

### Step 1: Find the Downloaded File
Once the download finishes, open your File Explorer. Check your "Downloads" folder or the location where your browser saves files. The file name will end with `.exe` or `.zip`.

### Step 2: Run the Installer
- If you downloaded a `.exe` file: Double-click the file. Windows may ask for permission—click "Yes" to allow it to run.
- If you downloaded a `.zip` file: Right-click the file and choose "Extract All," then open the extracted folder and double-click the application inside.

### Step 3: Follow the Setup Wizard
A setup wizard will appear on your screen. Follow these steps:
- **Accept the License Agreement:** Read and agree to the terms.
- **Choose Installation Location:** Use the default location (recommended).
- **Select Components:** Keep all options selected for a full installation.
- **Wait for Installation:** The process may take a few minutes. Do not turn off your computer.

### Step 4: Launch Alteryx Designer
After installation, you can find Alteryx Designer in your Start Menu. Click its icon to open it. You may need to sign in or activate the software—follow the on-screen prompts.

## ❓ Troubleshooting

### Common Issues and Solutions

**"Unable to find specified file"**
- Make sure you downloaded the correct file. Restart the download if needed.

**Installation stalls or freezes**
- Close other programs running in the background. Restart your computer and try again.

**Software won't open after installation**
- Right-click the Alteryx icon and select "Run as administrator."
- Check your antivirus settings—it might be blocking the software. Temporarily disable it and try again.

**Missing features or tools**
- Re-run the installer and select "Repair" or "Modify" to add missing components.
