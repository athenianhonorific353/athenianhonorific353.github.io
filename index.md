## ✨ What Tiller Does

Tiller combines a Chromium page engine with a native Mac interface. Pages render with Chromium through CEF, while the window, tabs, and menus are built with AppKit. That means you get modern web page support inside a browser that feels like a desktop app rather than a web page in a frame.

The built-in agent panel sits alongside the browser and can drive the browser. You can browse in the same window while using the panel, which makes Tiller useful for reading, research, and everyday web tasks.

## 🧭 Everyday Browsing

Tiller includes the browser tools most people expect:

- Tabs along the top or in a sidebar, with a context menu for tab actions.
- Session restore for open tabs and recently closed tabs after a restart or crash.
- A start page that brings closed tabs back.
- Find in page and zoom controls.
- Printing support.
- A link’s address shown under the mouse.
- Pages that can go full screen.
- Chromium’s developer tools and view source.
- Camera and microphone access for video calls, asked about per site.

Tabs can be arranged in the way that suits you. Keep them across the top for a familiar look, or use the sidebar when you have many pages open. The context menu gives you quick access to common tab actions without leaving the page.

Session restore is useful when you close Tiller by accident, restart your Mac, or come back after a crash. Open tabs and recently closed tabs survive restarts, and the start page helps you return to pages you closed.
